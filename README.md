## How to Use This Repository

1. **Register** your GitHub account
2. **Star** this repository
3. **Raise issues** to ask questions (coding & task questions)
4. **Learn and collaborate** with GitHub — put every in-class task and your group project on GitHub

Weekly code, data and announcements are organised by week under `Lecture Notes/`.

## Ground Rules

- Keep an open mind — AI changes every month, and so will we
- Speak English in class, including in group discussions
- Participate in in-class practices, homework and the group project
- Ask questions any time — there are no silly questions
- Academic integrity: your homework and project must be your own work. Using GenAI is allowed where stated — but you must say how you used it and understand every line you submit.

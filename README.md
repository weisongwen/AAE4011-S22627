## Intended Learning Outcomes

Upon completion of the subject, students will be able to:

1. **Apply** AI algorithms or adopt AI tools in solving engineering problems in unmanned autonomous systems.
2. **Understand** the relationship between multiple functions of unmanned autonomous systems, including perception, path planning, decision making and control.
3. **Design** partial functions of typical unmanned autonomous systems, such as positioning and path planning.
4. **Improve** existing AI algorithms for specific unmanned autonomous systems applications.

## Getting Started

1. Create a [GitHub account](https://github.com/signup) if you do not already have one.
2. **Star** and **Watch** this repository to receive announcements.
3. Open the notebooks for each week in [Google Colab](https://colab.research.google.com/) or a local Python environment (set-up instructions are given in Week 2).
4. Raise questions through [GitHub Issues](../../issues); please search existing issues first.

## Academic Integrity

All homework and project work must be the student's own. The use of generative AI tools is permitted only where explicitly stated. Where such tools are used, students must declare how they were used and must be able to explain every part of their submission. Breaches are handled in accordance with the University's regulations on academic integrity.
